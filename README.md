# About the Project

Restaurant Billing System is a software project I designed and developed to simplify restaurant operations through a local-network architecture.

The system consists of two Flutter applications: a cashier application that acts as the central server and a waiter application that connects to it. It uses HTTP, WebSockets, and UDP discovery to support real-time communication, automatic device discovery, and synchronized restaurant operations without requiring a continuous internet connection.

*Development*: System architecture and software implementation by Yohannes Tsegaye.

*Documentation*: Project documentation prepared with assistance from an intern.
